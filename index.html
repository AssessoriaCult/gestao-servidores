Termo de Uso de Dados

Em conformidade com a Lei Geral de Proteção de Dados (LGPD – Lei nº 13.709/2018), informamos que este sistema coleta e trata dados pessoais exclusivamente para fins de gestão interna institucional da Secretaria Municipal de Cultura de Araçatuba.

  • Os dados são utilizados apenas para gestão administrativa dos servidores
  • Não compartilhamos dados com terceiros
  • O acesso é restrito a usuários autorizados pela administração
  • Você pode solicitar a exclusão dos seus dados a qualquer momento
  • Os dados são armazenados de forma segura com controle de acesso

Importar / Exportar Dados de Servidores
Sistema sem dados de servidores

Nenhum dado pessoal está embutido no código por segurança (LGPD). Para carregar seus dados, use o botão "Importar JSON" abaixo com o arquivo de dados, ou cadastre servidores manualmente.

Os dados importados são gravados no banco do sistema. O arquivo exportado contém dados pessoais: guarde-o em local seguro e apague cópias desnecessárias.

LGPD – Gestão de Dados

Em conformidade com a LGPD, o administrador pode remover dados de servidores que solicitarem exclusão. Os dados ficam no banco de dados do sistema, com acesso restrito por perfil, e podem ser exportados ou excluídos individualmente. Nenhum dado pessoal está presente no código-fonte deste sistema. Ao sair, a cópia temporária guardada no navegador é apagada.
